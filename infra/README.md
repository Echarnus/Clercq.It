# Clercq.It Infrastructure

This directory contains Terraform configurations for deploying the Clercq.It Portfolio infrastructure to Scaleway.

## Infrastructure Components

- **Serverless Container**: Auto-scales 0-1 vCPU with 128MB memory
- **Serverless SQL**: PostgreSQL database with minimal resource allocation
- **Organization**: ClercqIt with Portfolio namespace
- **Cost Optimization**: Infrastructure scales to zero when not in use

## Prerequisites

1. **Scaleway Account**: Access to Scaleway with ClercqIt organization
2. **Scaleway Project**: A project created within the ClercqIt organization
3. **Terraform**: Version 1.0 or higher
4. **Scaleway Credentials**: Access key and secret key
5. **Container Image**: Docker image pushed to a registry (Docker Hub)

## Setup Instructions

### 1. Configure Variables

Copy the example variables file:
```bash
cp terraform.tfvars.example terraform.tfvars
```

Edit `terraform.tfvars` with your actual values:
- `scaleway_organization_id`: Your ClercqIt organization ID
- `scaleway_project_id`: Your Scaleway project ID (within the organization)
- `container_image`: Docker image tag (e.g., `echarnus/clercq-it:v1.0.0`)
- `custom_domain`: Optional custom domain

**Note**: Database password is now auto-generated by Terraform. No need to configure it manually.

### 2. Initialize Terraform

```bash
cd terraform
terraform init \
  -backend-config="access_key=$SCW_ACCESS_KEY" \
  -backend-config="secret_key=$SCW_SECRET_KEY"
```

The S3 backend bucket (`clercq-it-terraform-state`) should already exist. Terraform init will automatically connect to it for state management.

### 3. Plan Deployment

```bash
terraform plan
```

### 4. Deploy Infrastructure

```bash
terraform apply
```

### 5. Verify Deployment

After successful deployment, Terraform will output:
- Database endpoint and connection details
- Container URL
- Infrastructure summary

## Integration with CI/CD

This infrastructure is designed to integrate with the existing GitHub Actions workflows:
- `build.yml`: Builds and pushes container images
- `deploy.yml`: Can be extended to deploy to this infrastructure
- `infra.yml`: Manages infrastructure deployment and updates

### Pull Request Configuration

Key requirements for infrastructure PRs:
- All required Scaleway secrets must be configured (see [DevOps guide](../docs/devops.md#required-secrets))
- Terraform configuration must be validated
- Infrastructure impact must be assessed
- Changes require team review and approval

## Useful Commands

```bash
# Check infrastructure state
terraform state list

# View outputs
terraform output

# Destroy infrastructure (be careful!)
terraform destroy
```
